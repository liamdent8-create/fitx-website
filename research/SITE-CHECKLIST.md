# "30 reasons your site looks vibecoded": checklist

Source: reel by @niki.aroca (Instagram), checked against the site on 6 Nov 2026. Re-run before launch.

| # | Item | Status | What we did / why it's fine |
|---|---|---|---|
| 1 | Purple-to-blue gradients | Pass | None. Navy, white and one volt accent |
| 2 | 3 feature cards in a row | Pass | Timetable "Good to know" changed from 3 cards to a plain list. Remaining rows of 3 are real content (reviews, ways to book) |
| 3 | Fake testimonials | Pass | Only real Google and Mindbody reviews, word for word, with source. Staff and family reviews left out |
| 4 | Sparkle icons everywhere | Fixed | Ticker separator ✦ replaced with the X from the logo |
| 5 | "It's not X, it's Y" copy | Fixed | "Not the day you buy" rewritten |
| 6 | Gradient headline text | Pass | None |
| 7 | Glassmorphism everywhere | Fixed | Offer and contact panels are now solid. Glass kept only on the floating mobile bar, where it's functional |
| 8 | Pointless terminal windows | Pass | None |
| 9 | Generic buzzword copy | Pass | Scanned for elevate/unlock/transform/journey/seamless etc.: none in the copy |
| 10 | Untouched shadcn/ui | Pass | Not used; components are custom |
| 11 | Glowing background orbs | Pass | None. The neon outline on "UNLIMITED" echoes the studio's real neon sign |
| 12 | Emojis in every heading | Pass | None (emojis appear only inside quoted reviews, as written) |
| 13 | Badges above headlines | Fixed | Removed the "Now open" pill above the urgency headline. Kept: the $89 offer badge and the "Best value" tag |
| 14 | Em dashes everywhere | Pass | None in the copy |
| 15 | Lucide icons everywhere | Pass | No icon library |
| 16 | Empty bento grids | Fixed | "Shot needed" boxes replaced with text tiles until photos exist |
| 17 | Generic 3-tier pricing | Pass | Four memberships with Premium as the anchor, a value stack and a comparison table |
| 18 | Everything fades on scroll | Fixed | Entrance animation only for what's on screen when the page opens; nothing fades in on scroll |
| 19 | Cursor-following beams | Pass | None |
| 20 | Low-contrast dark mode | Pass | No dark mode; body text contrast is AA or better, volt on navy 14.8:1 |
| 21 | Inconsistent spacing | Pass | Shared section padding and gutter tokens on every page |
| 22 | Vague button labels | Fixed | "Claim" became "Claim 2 weeks"; every button says what happens ("Try 2 weeks for $89", "Book a class") |
| 23 | No real product demos | Fixed | Made-up app screen removed until real screenshots arrive. Real studio photos and the live Mindbody timetable throughout |
| 24 | Claims without proof | Pass | Claims backed on the page: reviews for beginners and coaching, real price maths for "Best value" |
| 25 | Forms asking for too much | Pass | No forms yet. The planned contact form asks only name, mobile, email and question |
| 26 | Keyboard-unfriendly forms | Pass | Tabbed through studio, mums and bubs, FAQ and timetable: every stop visible with a focus ring |
| 27 | Broken third-party embeds | Pass | Mindbody widgets checked loading; fallback link after 12 seconds; video loads only on tap |
